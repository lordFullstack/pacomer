# LOOP 11 — AUDITORÍA Y SEGURIDAD

## Objetivo
Crear trazabilidad administrativa.

## Registrar
login, logout, venta, cobro, fiado, abono, corrección, liberación, gasto, pago proveedor, apertura, cierre, reapertura y cambios de configuración.

## UI
Pantalla Auditoría con filtros por fecha, usuario, módulo y acción.

## Aceptación
Cada operación crítica tiene actor + timestamp + acción + referencia.
No permitir editar/borrar logs desde UI normal.
