# LOOP 13 — QA OPERATIVO

## Objetivo
Crear matriz de regresión y probar flujos reales.

## Casos
Mesas, clientes, crédito, proveedores, caja, roles, offline, backup, auditoría y dashboard.

## Aceptación
- Evidencia de cada flujo.
- Cero fallos P0/P1 abiertos.
- Smoke test repetible.
- Errores de red probados.
