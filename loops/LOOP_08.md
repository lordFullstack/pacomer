# LOOP 08 — DASHBOARD GERENCIAL

## Objetivo
Crear un centro de control para ADMIN usando datos ya confiables.

## KPIs obligatorios
Ventas hoy, ventas vs periodo anterior, ventas por tipo, mesas ocupadas/libres/atendidas, ticket promedio, caja, cartera, proveedores, hora pico, operaciones por hora, ventas por usuario, correcciones/anulaciones.

## Filtros
Hoy / 7 días / 30 días.

## Regla
No inventar KPI sin datos. Si falta catálogo de productos, dejar preparado el lugar pero no mostrar métricas falsas.

## Aceptación
Todos los KPI deben poder rastrearse hasta movimientos/transacciones reales.
