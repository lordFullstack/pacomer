# DECISIONES DE PRODUCTO

1. La pantalla principal Mesas se conserva.
2. Los módulos secundarios sí se pueden rediseñar y mejorar.
3. El dashboard es gerencial y debe priorizar KPIs accionables.
4. El sistema debe ser rápido para operación real.
5. Seguridad backend es obligatoria.
6. Datos financieros deben ser transaccionales.
7. Offline-first se implementará después de estabilizar dominio y transacciones.
8. No mostrar métricas falsas por falta de datos.
